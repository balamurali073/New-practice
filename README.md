## 🚀 Overview

This single-page portfolio features a responsive space-station cabin UI, an interactive BB-8 style droid guide with section-based dialogues, animated status gauges, and a clean project showcase.

### Highlights
- 🛸 **Sci-Fi HUD Design**: Built with responsive CSS grid/flexbox, custom glowing indicators, radar elements, and Orbitron/Rajdhani typography.
- 🤖 **Interactive Droid Guide**: Animated CSS droid assistant that delivers contextual updates as you navigate through sections.
- ⚡ **Lightweight & Fast**: Zero external JavaScript frameworks — purely semantic HTML5, CSS3, and modern vanilla JavaScript.
- 📱 **Fully Responsive**: Optimized for desktop, tablet, and mobile displays.

## 🌐 Deployment

### Deploy on Vercel
1. Import this repository at [vercel.com/new](https://vercel.com/new).
2. Keep default settings (`index.html` at root).
3. Click **Deploy**.

### Run Locally
Simply open [`index.html`](index.html) in any modern web browser or serve via:
```bash
npx serve .
```
